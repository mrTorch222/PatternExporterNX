# Проверка экспорта труб — 8 сентября 2026

Основа параметров и проверки геометрии: предоставленный `FrameGenerator_IGES_Exporter_Analytic.vb`.

- SDK: 9.0.317; целевая платформа приложения сохранена: .NET 8 / Windows x64, C# 12.
- Release x64: сборка без предупреждений и ошибок.
- Автоматические тесты: 28 пройдено, 0 ошибок. Проверены новые значения по умолчанию и сохранение явно заданных старых параметров после JSON round-trip.
- Интеграционная проверка: Inventor 2027.1, временная круглая труба длиной 100 мм, наружным диаметром 40 мм, внутренним диаметром 34 мм; дополнительный видимый эскиз вне тела. Тестовый документ закрыт без сохранения.
- Параметры: `GeometryType=0`, `SolidFaceType=1`, `SurfaceType=1`, `IncludeSketches=false`, `export_fit_tolerance=0.001` см.
- Экспорт через `FrameIgesExporter` успешен, журнал содержит параметры, геометрию, размер и путь файла. IGES содержит 6 поверхностей типа 144; типов 186 и 514 нет.
- В данном тесте базовые поверхности записаны Inventor как NURBS типа 128, несмотря на `SolidFaceType=1`. Передача параметра Analytic не означает подтвержденное наличие цилиндров типа 192 в итоговом файле.
- После добавления второго solid-тела экспортер возвращает ошибку, число успешных экспортов равно нулю, путь результата в строке очищен.

Новые настройки по умолчанию: «Поверхности / Аналитические / IGES 144». Ранее сохраненные значения не перезаписываются; для них эти три параметра нужно выбрать вручную.

Не проверены: экспорт реальной сборки Frame Generator через интерфейс и импорт IGES в TubesT. DXF-логика не изменялась; новая ручная проверка DXF, измерение ошибки сплайнов и проверка масштаба в программе резки не выполнялись.

## Развитие экспорта и разверток

После базовой проверки добавлены STEP, SAT и STL. Одна временная тестовая труба успешно экспортирована Inventor 2027.1 во все четыре формата: IGES, STEP, SAT и STL; каждый итоговый файл имеет ненулевой размер. Проверка многотельной детали сохранена.

На открытой листовой детали `ЛотВнМ.ipt` проверен анализ гибов: 4 физических гиба, самый длинный гиб 200 мм, 0 вверх и 4 вниз для текущей верхней стороны. Дублирующие результаты нижней стороны Inventor исключаются. Переворот `FlipBaseFace` поменял направления гибов, после проверки исходное значение было восстановлено.

Режимы верхней стороны DXF: как в модели, большинство гибов вверх и большинство гибов вниз. При равном количестве ориентация модели сохраняется. Переворот применяется только на время `WriteDataToFile`, затем исходная ориентация восстанавливается в `finally`.
