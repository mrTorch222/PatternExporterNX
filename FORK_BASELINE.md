## Базовая сборка до изменения кода

Команда: `dotnet build .\FlatPatternExporter.sln -c Release -p:Platform=x64`.

1. Установлен .NET SDK `8.0.204`. Источники NuGet в локальной конфигурации отсутствовали (`dotnet nuget list source`: «Источники не найдены»).
2. Первая сборка завершилась `NU1100`: не разрешены ClosedXML 0.105.0, Microsoft-WindowsAPICodePack-Shell 1.1.5, netDxf.netstandard 3.0.1, Svg.Skia 3.2.1 и stdole 17.14.40260.
3. `dotnet restore .\FlatPatternExporter.sln --source https://api.nuget.org/v3/index.json` успешно восстановил зависимости без изменения глобальной конфигурации NuGet.
4. Повторная сборка с `--no-restore` завершилась `NETSDK1140`: `10.0.26100.0` не является допустимой `TargetPlatformVersion` для установленного SDK. Это исходная проблема окружения, возникшая до переименования.
5. В исходном проекте interop указывает на Inventor 2026. На машине обнаружена установка Inventor 2027; переход ссылки остается этапом 1 плана.

## Непроверенное и следующий этап

Inventor на момент проверки не был запущен. Ручной запуск приложения, подключение через COM, экспорт эталонов, визуальный preview и импорт в программу резки не выполнены. Эталонных DXF в рабочей папке не было; заголовки `$INSUNITS`/`$MEASUREMENT`, координаты и представление SPLINE не измерялись.

Преобразование сплайнов, максимальная ошибка преобразования и расчет длины реза еще не реализованы и не измерены. Планируемое правило длины: сумма итоговых наружных и внутренних режущих профилей, с явным переводом известных единиц только для отображения в мм и м. Геометрия DXF автоматически не масштабируется.

Полная компиляция приложения, работа без копирования Autodesk interop (`Private=false`), выпуск всех архивов и установка обновлений требуют последующей проверки. До первого выпуска форка GitHub Releases API может возвращать 404 при проверке обновлений; релизы исходного проекта не используются.

Дальнейшая работа: подготовить совместимый SDK, выполнить этапы 0–6 из `IMPLEMENTATION_PLAN.md`. Переименование не является приемкой интеграции с Inventor 2027.
